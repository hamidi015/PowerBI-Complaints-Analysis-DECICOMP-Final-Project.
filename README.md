# Power BI Complaints Analysis Dashboard

## 📊 Project Overview
This project is a multi‑page Power BI dashboard analyzing customer complaints, broker performance, satisfaction levels, and complaint resolution trends.  
It was developed as part of the ReDI School Power BI course (Final Presentation: August 2026).

The dashboard provides a clear, interactive, and business‑ready view of complaint data using slicers, KPIs, charts, and summary insights.

---

## 🗂️ Pages Included

### **1. Overview Page**
- High‑level summary of complaints  
- Filters for Region, Product, Broker  
- Basic charts showing distribution of complaints  

---

### **2. Complaint Breakdown**
- Complaints by Product  
- Complaints by Region  
- Complaints by Broker  
- Interactive slicers  
- Helps identify where most complaints come from  

---

### **3. Status Analysis**
- Open vs Closed complaints  
- Trend of complaint resolution over time  
- Helps understand workload and resolution efficiency  

---

### **4. Satisfaction & Worst Brokers**
- Average client satisfaction  
- Satisfaction distribution  
- Worst performing brokers (highest complaints)  
- Helps identify improvement areas  

---

### **5. Executive Summary**
Contains key KPIs:
- **Total Complaints**  
- **Open Complaints**  
- **Closed Complaints**  
- **Average Satisfaction**  
- **Total Brokers (707)**  

Also includes a written summary answering the business questions.

---

## 🔑 Key KPIs Explained

### **Total Complaints**
Total number of complaints in the dataset.

### **Open Complaints**
Complaints still unresolved.

### **Closed Complaints**
Complaints successfully resolved.

### **Average Satisfaction**
Average client satisfaction score (0–1 scale).  
Example: **0.89 = 89% satisfaction**.

### **Total Brokers**
Number of unique brokers in the dataset.  
In this project: **707 brokers**.
